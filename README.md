## ⚙️ خطوات التشغيل

### 1. تثبيت المكتبة
```

```

### 2. عدّل config.py فقط
- ضع التوكنات الثلاثة
- ضع IDs القنوات
- ضع IDs الرولات

### 3. شغّل كل بوت في تيرمنال منفصل
```
python main_bot.py
python protection_bot.py
python ticket_roles_bot.py
```

## 🤖 البوتات الثلاثة

### 🪶 main_bot — القوانين والترحيب
- رسالة ترحيب تلقائية عند الانضمام
- رسالة القوانين مع زر "قبلت القوانين"
- يعطي رول العضو عند القبول
- لوق الانضمام والمغادرة
- أمر `!rules` للأدمن

### 🛡️ protection_bot — الحماية والموديريشن
- **Anti-Spam** — كتم تلقائي عند السبام
- **Anti-Raid** — تنبيه عند انضمامات كثيرة
- **Anti-Link** — حظر روابط للأعضاء الجدد
- **حساب مشبوه** — تنبيه للحسابات الجديدة
- لوق حذف وتعديل الرسائل

**أوامر الموديريشن:**
```
!warn @member [reason]     — تحذير
!mute @member [minutes]    — كتم
!unmute @member            — رفع الكتم
!kick @member [reason]     — كيك
!ban @member [reason]      — باند
!unban [user_id]           — رفع باند
!clear [amount]            — حذف رسائل
!warns @member             — عرض التحذيرات
```

### 🎫 ticket_roles_bot — التيكت والرتب
- نظام تيكت كامل مع قنوات خاصة
- زر **طلب اعطاء رتبة** ✅
- زر **طلب سحب رتبة** ❌
- الطلب يصل للأدمن مع أزرار قبول/رفض
- إشعار للعضو بنتيجة الطلب عبر DM

**أوامر الإعداد (مرة واحدة فقط):**
```
!setup_roles    — إرسال رسالة طلب الرتب
!setup_ticket   — إرسال رسالة فتح التيكت
```
